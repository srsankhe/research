## Color Coding

- Red (>5%): High enrichment
- Blue (2-5%): Moderate enrichment  
- Gray (<2%): Low enrichment

## Dot/Scatter Plot Legend

- **Size**: Number of overlapping DE genes
- **Color**: Pathway size (number of genes in pathway)
